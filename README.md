# 游戏内GPU模拟器与渲染管线系统

## 项目描述

游戏内GPU模拟器与渲染管线系统的bug修复项目。核心模块 `rendering/gpu_simulator.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 顶点处理器完全没做顶点数据直接通过不变换
- 光栅化器完全没做三角形不能变成像素
- 片元处理器完全没做像素颜色是固定的
- 纹理采样完全没做贴图都是模糊的
- 帧缓冲完全没做渲染结果不能保存

## 运行测试

```bash
python -m pytest tests/test_gpu_simulator.py -q
```

修复目标：所有 16 个测试全部通过。

## 技术要求

- 纯Python标准库，不引入第三方依赖
- 不修改测试文件
- 保持现有API接口不变
